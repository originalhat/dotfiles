# 1. Record architecture decisions

Date: 2026-11-24

We record decisions about this repo as short ADRs in `docs/adr`, following [Michael Nygard's format](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions). Each one says what we decided and why, so future changes (by me or an agent) don't undo the reasoning by accident. Superseded ADRs stay, marked as superseded.

Inspired by [nateberkopec/dotfiles](https://github.com/nateberkopec/dotfiles/tree/main/docs/adr).
